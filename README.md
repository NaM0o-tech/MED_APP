## School's Project Application

# Time Med

แอปพลิเคชั่นแจ้งเตือนการกินยา รูปแบบง่าย

## จุดประสงค์

เพื่อเตือนการกินยาในแต่ละวัน เหมาะสำหรับผู้ใหญ่และผู้สูงอายุ

## จุดเด่นของแอปนี้

-สามารถสร้างรายการยาได้เอง
-สามารถระบุวันที่ เวลา และจำนวนเม็ดยา ที่รับประทานได้
